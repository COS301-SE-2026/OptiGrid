INTRODUCTION

OptiGrid is a centralised energy intelligence platform for the built environment. It ingests meter readings from offices, hospitals, schools, shopping centres, and industrial sites, then surfaces what is consuming energy, where it is wasted, and what to do about it.

The platform combines real-time monitoring, anomaly detection, demand forecasting, and optimisation recommendations into a single dashboard-first experience. Operators stop reacting to bills after the fact and start making decisions on live data.

DESIGN PRINCIPLES

P/01
Clarity over decoration
A user should read the most important number on a screen without scanning. Metrics are large, mono, and unambiguous.
P/02
Consistency
A button, badge, or card looks the same on every screen. Tokens, not bespoke styles.
P/03
Responsive
Every screen works from 360px upward. The sidebar collapses to a top nav below 768px.
P/04
Accessible first
Visible focus rings, labelled inputs, colour never the only signal. WCAG 2.1 AA.
P/05
Quiet by default
No carousels, no parallax, no modal-on-load. Motion limited to 150ms transitions.

ACCESSIBILITY

  • WCAG 2.1 AA. Every text/background pair verified against the 4.5:1 minimum for body text and 3:1 for large text and UI components.
  • Focus. Every interactive element exposes a visible focus ring. DOM order drives focus order; no positive tabindex values.
  • Labels. Every input has an associated label. Icon-only buttons carry an aria-label.
  • Keyboard. Modals trap focus and close on Escape. Tables and lists are navigable with arrow keys.
  • Screen readers. Semantic HTML by default. Status messages use role="alert".
  • Motion. No transition exceeds 200ms. prefers-reduced-motion disables transitions.
  • Theme. Light/dark toggle persists across sessions. Initial value respects prefers-color-scheme.
